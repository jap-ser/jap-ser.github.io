不動産の買取は、不動産会社が売主から直接物件を買い取る売り方で、「相談・査定 → 現地確認 → 価格の提示 → 売買契約 → 決済（代金の受け取り）と引渡し」という流れで進みます。買主を探す期間がないぶん、仲介より日程を決めやすいのが特徴ですが、買取価格は査定・物件確認のうえで判断されるため、事前に物件の状況と希望条件を整理しておくことが大切です。このページでは、金沢市で買取に出す前に確認したいことを、チェックリストの形でまとめます。

## 買取と仲介の違い

| | 買取 | 仲介 |
|---|---|---|
| 買う人 | 不動産会社 | 一般の買主（個人・法人） |
| 価格 | 査定・物件確認のうえで会社が提示。相場より低くなるのが一般的 | 市場で決まる。相場に近い価格を狙える |
| 期間 | 買主探しがないため、日程を決めやすい | 買主が見つかるまでの期間は物件と価格次第 |
| 内覧・広告 | 原則なし。近所に知られにくい | 内覧対応や広告掲載がある |
| 家財・建物の状態 | 現状のまま相談できる場合が多い | 片付けや手入れをしたほうが売れやすい |
| 仲介手数料 | 取引の形によってかかる場合がある。見積もりの段階で確認を | かかる |

価格がどう計算されるか、会社によって金額が違う理由は[不動産買取の価格はどう決まる？](/guide/kaitori-kakaku/)で詳しく解説しています。

## 相談から入金までの流れ

1. **相談・机上査定**：所在地、面積、築年数、売りたい理由と時期を伝えます。この段階で仲介と買取のどちらが向いていそうかの見通しが立ちます
2. **現地確認**：建物の状態、敷地と道路の関係、境界標、残置物の量などを確認します。空き家の場合は鍵の受け渡しで対応できることもあります
3. **買取価格と条件の提示**：価格に加えて、引渡しの時期、家財の扱い、測量の要否、費用の負担（解体・測量・登記など）を書面で確認します
4. **売買契約**：重要事項説明を受けて契約を結びます。手付金の有無や金額、契約不適合責任（引渡し後に見つかった不具合の責任）の扱いもここで決まります
5. **決済・引渡し**：残りの代金を受け取り、所有権の移転登記を行い、鍵を引き渡します。住宅ローンが残っている場合は、この日に代金で完済して抵当権を抹消するのが一般的です

契約から決済までの期間は、測量や相続登記の要否、引越しの都合によって変わります。

## 買取に出す前のチェックリスト

価格の提示を受ける前に、次の点を確認しておくと、話が早く進み、あとから条件が変わることを防げます。

- [ ] **名義**：登記上の所有者は誰か。亡くなった方の名義のままなら、先に相続登記が必要です（[相続した家・土地を売るときの順番](/guide/souzoku/)）
- [ ] **共有者の同意**：共有名義の場合、共有者全員が売ることに同意しているか
- [ ] **住宅ローンの残高**：買取価格で完済できるか。残高証明や返済予定表で確認
- [ ] **境界**：境界標があるか、隣地との間で境界に争いがないか
- [ ] **建物の不具合**：雨漏り、傾き、シロアリ、給排水の故障など、知っていることを書き出す
- [ ] **家財の扱い**：残したまま引き渡したいか、自分で片付けるか
- [ ] **引渡しの希望時期**：引越し先が決まっているか、いつまでに現金化したいか
- [ ] **費用の負担**：解体・測量・残置物の処分・登記・仲介手数料のうち、どれを誰が負担するか

不具合は伝えると価格が下がるのではと心配されがちですが、買取の場合は会社側が現地確認でリスクを見込んだうえで価格を出すため、先に伝えておくほうが、契約後に条件が変わるおそれを減らせます。

## 用意しておく書類

- 固定資産税の納税通知書（課税明細書）
- 登記済権利証または登記識別情報
- 本人確認書類と印鑑証明書（契約・決済の段階で必要）
- 購入時の売買契約書・重要事項説明書（税金の計算にも関わります）
- 測量図・境界確認書（あれば）
- 住宅ローンの残高がわかる書類（ローンがある場合）
- 建物の図面・リフォームの記録（あれば）

相続した物件では、これに加えて戸籍や遺産分割協議書などが必要になります。手続きは司法書士に依頼するのが一般的です。

## 買取が向いているケース・仲介を先に考えたいケース

**買取が向いていることが多いケース**

- 古い家が建っていて、解体するか迷っている（[古い家が建っている土地の売り方](/guide/furuie/)）
- 家財が多く、片付けに行く時間や体力がない
- 近所に知られずに売りたい、内覧対応が負担
- 引越しや相続の分割など、日程を先に決めたい
- 雨漏りや傾きなど、一般の買主に敬遠されそうな事情がある

**仲介を先に考えたいケース**

- 建物の状態がよく、時間に余裕がある
- 人気のある町名で、取引件数が多い（町名ごとの件数と価格は[金沢市の町名一覧](/kanazawa/)で確認できます）
- できるだけ高い価格を優先したい

どちらか迷う場合は、両方の見込み額を並べてもらい、手取りと期間で比べるのが確実です。

## 売却後の税金について

買取でも、売却益が出れば仲介と同じく譲渡所得として課税の対象になり、翌年に確定申告が必要になる場合があります。自宅や相続した空き家の売却には控除の特例がありますが、適用できるかどうかは個別の事情によります。一般的な仕組みは[売却にかかる費用と税金の全体像](/guide/hiyou-zeikin/)を参考にし、最終的な確認は税理士・税務署へお願いします。

## 当社の場合

当社は金沢市・野々市市を中心に、仲介と買取の両方をお受けしています。ご相談の際は、仲介で売り出した場合の想定価格と、当社が買い取る場合の価格を並べてご説明します。買取価格は査定・物件確認のうえで判断し、仲介手数料を含む費用の有無や引渡しの時期・家財の扱いなどの条件も、契約前に書面でご確認いただけます。ご相談だけ、机上査定だけでもお気軽にどうぞ。

## よくある質問

**Q. 買取を相談したら、その会社に売らないといけませんか？**
A. 相談や査定を受けただけで売る義務はありません。提示された価格や条件に納得できなければ断れますし、仲介や他社の見積もりと比べてから決めて問題ありません。

**Q. 家財が残ったままでも買取してもらえますか？**
A. 現状のまま相談できる場合が多いですが、処分費用を買取価格に織り込むか、売主が別に負担するかは会社や物件によって違います。どの物をどこまで残してよいか、費用の扱いを含めて事前に書面で確認してください。

**Q. 買取でも仲介手数料はかかりますか？**
A. 不動産会社が直接買主になる取引では、仲介手数料がかからないことが一般的ですが、間に別の会社が入る取引など、取引の形によってはかかる場合があります。見積もりの段階で、手数料の有無と金額を確認しておくと安心です。
