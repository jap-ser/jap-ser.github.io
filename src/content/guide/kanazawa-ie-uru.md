金沢で家を売るときの流れは、「相場を調べる → 査定を受ける → 売り方と価格を決める → 売り出す → 売買契約 → 引渡し」の6段階です。仲介で一般の買主を探す場合は、売り出しから引渡しまで数か月かかるのが一般的で、物件や価格によってはそれ以上かかることもあります。急ぐ事情がある場合や手間を減らしたい場合は、不動産会社が直接買い取る「買取」も選択肢になります。ここでは、初めて家を売る方に向けて、各段階でやることを順に説明します。

## 家を売る流れ（全体像）

| 段階 | やること | ポイント |
|---|---|---|
| 1. 相場を調べる | 町名ごとの取引価格を確認 | 売り出し価格ではなく取引された価格を見る |
| 2. 査定を受ける | 机上査定 → 訪問査定 | 仲介と買取の両方の見込みを聞く |
| 3. 売り方を決める | 仲介なら媒介契約を結ぶ | 契約の種類は3つ |
| 4. 売り出し・内覧 | 広告、内覧の対応 | 片付けと掃除で印象が変わる |
| 5. 売買契約 | 契約書の締結、手付金の受け取り | 不具合は書面で伝える |
| 6. 決済・引渡し | 残代金の受け取り、登記、鍵の引渡し | ローンの完済と抵当権の抹消も同日に行う |

## 1〜2. 相場を調べて査定を受ける

まず、家がある町名の相場を確認します。本サイトの[金沢市の町名別相場ページ](/kanazawa/)では、国土交通省が公開している実際の取引データをもとに、土地・戸建・マンションの価格の目安を町名ごとに見られます。

そのうえで不動産会社に査定を依頼します。査定には、資料だけで概算を出す「机上査定」と、現地で建物の状態や道路・境界を確認する「訪問査定」があります。査定額は「この価格で売れる」という約束ではなく見込みですので、金額の高さだけでなく根拠を聞くことが大切です。準備するものは[不動産の無料査定を受ける前に知っておくこと](/guide/muryou-satei-mae/)に、査定書の読み方は[査定書の見方と、複数社の査定を比べるコツ](/guide/satei-no-mikata/)にまとめています。

## 3. 媒介契約の種類を選ぶ

仲介で売る場合は、不動産会社と媒介契約を結びます。種類は3つあります。

| | 一般媒介 | 専任媒介 | 専属専任媒介 |
|---|---|---|---|
| 依頼できる会社の数 | 複数社 | 1社 | 1社 |
| 自分で見つけた買主との直接契約 | できる | できる | できない |
| 売主への状況報告 | 定めなし | 2週間に1回以上 | 1週間に1回以上 |
| 指定流通機構（レインズ）への登録 | 任意 | 義務 | 義務 |
| 契約期間 | 定めなし（3か月以内が目安） | 3か月以内 | 3か月以内 |

どれが良いかは物件と考え方によります。窓口を一つにして報告を受けながら進めたい場合は専任系、複数の会社に声をかけたい場合は一般媒介が選ばれます。

## 4. 売り出しから内覧まで

売り出し価格は、査定額と相場、売りたい時期をもとに決めます。高めに出して反応を見る方法もありますが、長く売れ残ると「何か理由があるのでは」と見られることもあるため、見直しの時期をあらかじめ決めておくと安心です。

内覧では、片付け・掃除・換気といった費用のかからない準備が効果的です。大がかりなリフォームは元を取りにくいことが多いので、まずは現状で査定を受けてから判断してください（[家を売る前にリフォームは必要？](/guide/baikyaku-mae-reform/)）。

## 5〜6. 売買契約と引渡し

買主が決まると、価格・引渡し時期・残していく設備などの条件を詰め、売買契約を結びます。契約時に手付金を受け取り、残りの代金は引渡しのときに受け取るのが一般的です。

雨漏りやシロアリ、設備の故障など、知っている不具合は「物件状況確認書（告知書）」で書面にして伝えます。伝えずに売ると、引渡し後に修理費の負担などを求められるおそれがあります。

引渡しの日には、残代金の受け取り、住宅ローンの完済と抵当権の抹消、所有権移転登記の手続き、鍵の引渡しを同じ日に行います。固定資産税は引渡日を基準に日割りで精算するのが一般的です。ローンが残っている場合の注意点は[住宅ローンが残っている家を売る](/guide/loan-zandaka/)をご覧ください。

## 売却にかかる期間の考え方

仲介の場合、期間は大きく3つに分かれます。

- **売り出しまで**：査定、媒介契約、資料の準備。相続登記や境界の確認が必要な場合はその分長くなります
- **買主が見つかるまで**：もっとも読みにくい部分。価格、立地、時期によって変わります
- **契約から引渡しまで**：買主の住宅ローンの手続きや引越しの準備の期間

「いつまでに売りたいか」が決まっている場合は、最初の査定のときに伝えてください。期限から逆算して、売り出し価格や、途中で買取に切り替えるかどうかを相談できます。

## 金沢で家を売るときの注意点

- **冬の内覧**：積雪の時期は、駐車場や玄関までの除雪をしておくと内覧しやすくなります。屋根の落雪や融雪装置の有無は買主がよく確認する点です
- **駐車場の台数**：車での生活が中心の地域では、何台とめられるかが検討の決め手になることがあります
- **前の道の幅**：古くからの住宅地では道が狭い場所があり、建て替えのときに敷地の一部を道路として後退させる必要がある場合があります
- **空き家の管理**：売り出し中も、水道管の凍結や庭木の手入れなどの管理は続きます

## 仲介と買取の選び方、当社の場合

仲介は相場に近い価格を狙える一方、期間が読みにくく内覧の対応が必要です。買取は価格が仲介より低くなることが多いものの、買主を探す期間がなく、家財が残ったままでも相談しやすい方法です。

当社では、仲介で売り出す場合の見込みと、当社が買い取る場合の価格の両方をご相談いただけます。買取の可否と価格は、査定・物件確認のうえで判断します。税金や費用の全体像は[売却にかかる費用と税金の全体像](/guide/hiyou-zeikin/)をご覧のうえ、個別の税額は税理士か税務署にご確認ください。

## よくある質問

**Q. 住みながら家を売ることはできますか？**
A. できます。住みながらの売却は一般的で、内覧の日時を調整しながら進めます。引越し先が決まっていない場合は、引渡し時期を買主と相談して決めます。住み替えの順番は[住み替えの進め方](/guide/sumikae/)にまとめています。

**Q. 家を売るとき、最初に何をすればよいですか？**
A. まず町名の相場を確認し、固定資産税の納税通知書や購入時の書類を手元に用意したうえで、査定を依頼するのが一般的です。名義が亡くなった方のままの場合は、相続登記が先に必要になります。

**Q. なかなか売れないときはどうすればよいですか？**
A. 価格の見直し、広告内容や写真の見直し、片付けなどの印象の改善が主な対策です。一定期間たっても反応が少ない場合は、買取に切り替える方法もあります。媒介契約の更新の時期に、これまでの反響をもとに不動産会社と方針を話し合ってください。
